# Путеводитель Лондон → Лион — iOS-приложение

Готовый исходный код SwiftUI-приложения по вашему путеводителю v2 (23 дня, 05–27 сентября 2026, включая Брюгге). Три таба внизу экрана: **Календарь** (тап по дню → «План», «Карта», «Брони и билеты»), **Маршруты** (все переезды с картой и кнопкой Google Maps) и **Справка** (документы, деньги, погода, бюджет, план Б). Тёмный дизайн "ясной европейской ночи" с фотореалистичными анимированными фонами по городам и иконкой-коллажем. Работает на iPhone и iPad.

На экране дня можно свайпнуть влево/вправо, чтобы перейти к следующему/предыдущему дню без возврата в календарь. У каждого из 23 дней своя пасхалка: тройной тап по экрану «План» запускает косой дождь из одного фотореалистичного предмета, привязанного к этому дню, через весь экран. Через несколько секунд дождь гаснет сам, либо закрывается тапом.

Предмет по дням: 1 — корона Елизаветы II, 2 — Биг-Бен, 3 — гвардейский гвардеец, 4 — снитч (Гарри Поттер), 5 — секундомер с гоночным флагом (Top Gear), 6 — двухэтажный автобус, 7 — зонт и саквояж (Мэри Поппинс), 8 — телефонная будка, 9 — Эйфелева башня, 10 — багеты, 11 — карусельная лошадка (вместо Микки Мауса), 12 — настольная лампа (вместо лампы Pixar), 13 — колокольня в Брюгге, 14 — бутылка вина, 15 — дворец в Анси, 16 — медаль со снежинкой (вместо олимпийских колец), 17 — ледник, 18 — сноуборд, 19 — лыжи, 20 — снегоход, 21 — банный халат, 22 — веник для бани, 23 — кино-хлопушка.

Пять предметов заменены на generic-эквиваленты вместо охраняемых товарных знаков/персонажей: логотип Top Gear → секундомер с флагом, Мэри Поппинс → зонт и саквояж, силуэт Микки Мауса → карусельная лошадка, лампа Pixar → обычная настольная лампа, олимпийские кольца → медаль со снежинкой.

Таб-бары принудительно закреплены снизу (на iPadOS 18+ система по умолчанию уводит их наверх экрана — это исправлено через `.environment(\.horizontalSizeClass, .compact)` в `RootView.swift` и `DayDetailView.swift`).

## Что внутри

- `TripGuideApp.swift` — точка входа
- `RootView.swift` — нижний таб-бар (Календарь / Маршруты)
- `Theme.swift` — цветовая палитра и акценты по городам
- `NightCityScene.swift` — фотореалистичный анимированный ночной фон по городам (фото + дождь/снег/салют/мерцание поверх)
- `Models.swift` — модели данных дня
- `TripData.swift` — весь текст путеводителя, 23 дня
- `CalendarView.swift` — главный экран-календарь
- `DayDetailView.swift` / `DayPlanView.swift` / `MapTabView.swift` — экран дня (план + карта точек)
- `RouteModels.swift` / `RouteData.swift` / `RoutesView.swift` / `RouteDetailView.swift` — вкладка «Маршруты»
- `InfoView.swift` — справочный раздел (бронирования, документы, бюджет, план Б) — иконка ⓘ на календаре
- `Assets.xcassets/` — иконка приложения (AppIcon) и акцентный цвет

Данные полностью статичные — интернет приложению не нужен, кроме подложки карты (тайлы Apple Maps) и кнопки «Открыть в Google Maps».

## Шаг 1. Создать проект в Xcode

1. Откройте Xcode → **File → New → Project**.
2. Выберите **iOS → App**, нажмите Next.
3. Product Name: например `TripGuide`. Interface: **SwiftUI**. Language: **Swift**. Storage: **None** (важно — не выбирайте Core Data/SwiftData).
4. Сохраните проект в удобную папку.

## Шаг 2. Добавить файлы

1. В навигаторе слева удалите автосозданный `ContentView.swift` (Move to Trash).
2. Перетащите все `.swift`-файлы из этого набора в navigator проекта (галочка **Copy items if needed**, отмечен app target).
3. Замените дефолтный `Assets.xcassets` на прилагаемый: в Finder закройте Xcode, удалите папку `Assets.xcassets` внутри папки проекта и скопируйте на её место прилагаемую `Assets.xcassets` из этого набора (она уже содержит готовую иконку `AppIcon` и `AccentColor`). Снова откройте проект в Xcode и проверьте, что иконка отображается в `Assets.xcassets → AppIcon`.
4. Откройте `TripGuideApp.swift` и убедитесь, что `@main struct` в проекте только один (если Xcode создал свой файл входа с тем же именем — удалите дубликат).

## Шаг 3. Настройки проекта

1. Проект в навигаторе → target → **General**: minimum iOS deployment — поставьте **iOS 17.0** (вкладка «Маршруты» использует современный Map API с линией маршрута, ему нужен iOS 17+; на iPhone и iPad Air 11" (2025) это не проблема, оба поддерживают гораздо более свежие версии).
2. Там же, в **General → Supported Destinations** (в старых версиях Xcode — раздел **Deployment Info → Devices**) нажмите **+** и добавьте **iPad** рядом с iPhone (или сразу выберите **iPhone + iPad** при создании проекта в Шаге 1). Без этого шага приложение не установится на iPad.
3. Вкладка **Signing & Capabilities**: выберите Team — свой Apple ID (для начала подойдёт и бесплатный, без Developer Program).

Приложение уже адаптировано под iPad: на широком экране (iPad Air 11", Pro, обычный iPad) карточки и текст ограничены удобной для чтения шириной и выровнены по центру, а на iPhone и в узких режимах Split View/Slide Over всё остаётся как раньше, на всю ширину. Иконка приложения уже содержит все нужные размеры для iPad.

## Шаг 4. Запустить на телефоне или iPad (без платного аккаунта)

Подключите iPhone или iPad к Mac по кабелю, выберите нужное устройство как target, нажмите ▶️ Run. При первом запуске на устройстве: **Настройки → Основные → VPN и управление устройством** → доверять профилю разработчика.

Ограничение бесплатного Apple ID: приложение работает 7 дней, потом нужно пересобрать через Xcode. Для постоянной установки жене без вашего Mac нужен TestFlight — а для него уже нужен платный аккаунт (см. ниже).

## Шаг 5. TestFlight (когда будет платный Apple Developer аккаунт)

1. Оформите **Apple Developer Program** — developer.apple.com/programs, $99/год.
2. В Xcode: Signing & Capabilities → выберите платный Team, задайте уникальный Bundle Identifier (например `com.mike.tripguide2026`).
3. **Product → Archive** → Organizer → **Distribute App → App Store Connect → Upload**.
4. На appstoreconnect.apple.com создайте запись приложения с тем же Bundle ID → дождитесь обработки билда (10–30 минут).
5. Вкладка **TestFlight** → добавьте жену как внутреннего тестера по её Apple ID / email → она получит приглашение через приложение TestFlight.

## Что можно поменять

- Координаты точек и маршрутов — приблизительные (по названиям мест из путеводителя), для навигации по смыслу достаточно, но при желании уточните по факту.
- Цвета городов и акценты — в `Theme.swift`, функция `cityColor`.
- Ночные фото городов и погодная анимация — в `NightCityScene.swift` и `Assets.xcassets/Night*.imageset`.
- Маршруты (список переездов) — в `RouteData.swift`.
- Название приложения — стандартно через настройки target в Xcode.
- Максимальная ширина колонки на iPad — в `Theme.swift`, модификатор `readableWidth()` (по умолчанию 680pt).
- Пасхалки по дням — какой предмет падает дождём в какой день, в `EasterEggScene.swift` (`RainObject.forDay`); сам показ на весь экран по тройному тапу — в `DayPlanView.swift` (`triggerEasterEgg`/`easterEggOverlay`).
- Свайп между днями — жест в `Theme.swift` (`daySwipeNavigation`), состояние текущего дня — в `DayDetailView.swift`.
